Sierra 4 offline map resources

MapLibre GL JS 6.11.2, BSD-3-Clause. Full license: vendor/LICENSE.maplibre.txt.
Source: https://github.com/maplibre/maplibre-gl-js
Pinned archive: https://registry.npmjs.org/maplibre-gl/-/maplibre-gl-6.11.2.tgz
The integrity and local SHA256 values are recorded in assets-manifest.json.

Natural Earth 1:50m land geometry, public domain.
Source: https://www.naturalearthdata.com/about/terms-of-use/
Reuses the application's bundled ne_50m_land.geojson. It provides land/coastlines,
not live airport information, streets, buildings, political borders or imagery.

The browser palette is generated from SierraDesignTokens.xaml.
No fonts, city-light imagery, commercial tiles or remote map services are used.

Microsoft WebView2 SDK 1.0.4191.47 has its own Microsoft redistribution license.
Microsoft Evergreen WebView2 Runtime must already be installed separately.
Sierra 4 does not silently install a browser runtime.
