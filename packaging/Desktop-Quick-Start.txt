ALPHA 6 OPS — CHECKPOINT 7.16 / VERSION 0.21.0

LOCAL UPDATE
Exit OPS from its Exit OPS button or tray menu; the window X only hides it.
Run Alpha6OPS-Setup-0.21.0.exe to update the existing installation.
The installer preserves your logs, assignment, settings and SimBrief cache.
Open Alpha 6 OPS from Start and confirm v0.21.0 in the footer.
The portable ZIP is an alternative: extract it fully before starting Alpha6OPS.exe.
Flight Lab has been removed. Upgrading removes its installed folder and Start menu shortcut.
The desktop runtime remains because OPS requires it. No GitHub upload is required.

TRACKING CHANGES
Both progress bars now use a shared geographical route-distance calculation.
Short/duplicate route legs no longer trap the progress calculation at departure.
Hero arrival and the tracking footer share a published gate-IN estimate.
The estimate uses current movement and a five-minute taxi-in allowance; it is
not an ATC prediction and can change with speed, routing or holding.
Before a usable airborne estimate exists, ETA remains unavailable.
After block-in, actual IN replaces the estimate. Connecting after departure
does not invent an actual OUT time.

Tracking scheduled times now show UTC only. The footer uses
two rows so dates and times cannot overlap adjacent fields.
Map legend: yellow planned route, grey completed planned route, cyan flown trail.
The flown trail can legitimately differ from the flight plan.
Approach detection no longer requires a specific progress percentage.
Gradual gear transitions are recorded, and milestone event times are consistent.

CHECKPOINT 7.15
Enter departure and arrival gates in the Dispatch release before accepting.
Saved Gates remembers previous airport/airline/aircraft use; suggestions do not
indicate live availability. Save Gates in Dispatch can amend an active flight.
The tracking screen no longer has an Assign Gates button.
Review UTC Schedule corrects dated OUT/IN without resetting the flight.
Recorded actual times remain visible when a matching assignment needs review.
Map Follow is highlighted when enabled. Dragging or route fit disables it.
Engine readings now include optional fuel flow, spool and starter diagnostics.
Unknown engine data stays unknown. If automatic block-in cannot be verified,
Confirm Parked appears after landing and a sustained stopped/braked condition.
Flap events describe handle selection; optional surface angles are logged.
Before a long A220 test, verify a short engine-start/flap cycle in the new log.
No live gate provider or paid subscription is required.

CHECKPOINT 7.16
A32x handle indexes display UP, 1, 1+F, 2, 3 and FULL. Matching left/right
flap surfaces confirm physical movement without claiming unavailable slat data.
Engine shutdown remains visible while confirmed-running engines spool down.
Submit PIREP appears only after a recorded block-in/actual IN, and closeout
immediately clears the active Dispatch release.
Dispatch now displays airport names beneath both ICAO codes. Gate assignment
fields are compact, use clear saved-gate controls and can recommend gates after
at least two matching local-history uses for the same airport and airline.
Recommendations require pilot confirmation and do not indicate live availability.
