ALPHA 6 OPS — CHECKPOINT 7.17 / VERSION 0.22.0

LOCAL CHECKPOINT 7.22 — SIERRA 4 OPERATIONS MAP PREVIEW
The Operations map now offers a Use Map V2 button. This is an opt-in preview;
the classic map remains the default and is available as an immediate fallback.
Flight Tracking continues to use its existing map.
Map V2 uses bundled offline geography and needs no account, map key or tiles.
Microsoft Edge WebView2 Evergreen Runtime must already be installed. If it is
unavailable or the renderer fails, the classic map remains usable. This package
does not silently download/install WebView2 and does not include a Fixed runtime.
Use classic map switches back. The choice is for the current application session.
The application/profile names and version remain unchanged during UI migration.

CHECKPOINT 7.17
Changed departure procedures and direct routing can rejoin the planned route
without leaving progress frozen on an old segment. Both progress bars, distance,
route styling and the diagnostic journal share the computed progress.
Unreliable route position or unavailable telemetry suspends live ETA and delay
claims until usable data returns. Recorded actual IN remains unchanged.

An unavailable simulator registration is advisory when the live departure
location or simulator route independently verifies the assignment. Conflicting
routes, wrong departure locations and implausible dates still require review.

A220 handle indexes 0–5 display UP, 1, 2, 3, 4 and 5. Flap events identify the
selected configuration; raw surface measurements remain in diagnostic logs.
Selected does not mean that the moving surfaces have reached that position.
Engine shutdown wording identifies the evidence actually available.

Scheduled IN now uses SimBrief sched_in. The dispatch est_in is retained
separately as an initial prediction. Refresh the SimBrief release to obtain both
values; existing saved releases retain their original imported times.
Manual schedule corrections clear the older dispatch estimate.

Dispatch airport names align beneath their ICAO codes in draft and active
releases. Gate Assignments has a larger heading and yellow section accent.
Gate suggestions use your local confirmed history, not live availability.
