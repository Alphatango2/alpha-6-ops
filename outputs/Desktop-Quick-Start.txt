ALPHA 6 OPS - WINDOWS DESKTOP BUILD 0.16.0

START HERE
Exit an older OPS copy using Exit OPS, then run Alpha6OPS-Setup-0.16.0.exe.
Open Alpha 6 OPS from Start. Administrator access is not required.

CONSOLIDATED BUILD
Includes Dan's flight tracking checkpoints through 7.11 and Reece's account,
personal pilot workspace, simulator integration and performance work.
Open Dispatch to import and review SimBrief, accept a release, or enter a
flight manually. The OFP viewer and cached releases use the current workspace.
Account sign-in requires publisher Auth0 configuration; an unconfigured build
opens Local Preview. Real Auth0 and live MSFS acceptance are separate checks.

LAUNCH & CONNECT
Click the simulator card. If MSFS 2024 is closed, OPS launches the Microsoft
Store edition through Windows. If MSFS is already running, OPS connects directly.
Load a flight in MSFS; OPS keeps retrying while it starts and loads.
Disconnect cancels monitoring/retries without closing the simulator.
Sign-in, updates and flight selection are handled in the simulator.

LIVE FLIGHT IDENTIFICATION
You can fly without SimBrief. OPS observes the aircraft, registration and position,
checks the active simulator flight plan, and identifies nearby airports using MSFS
facilities with an offline airport reference as fallback.
A nearby airport does not establish a departure or intended destination.
When no destination is known, it remains unknown instead of using an old briefing.

A saved assignment is checked against live evidence before its route, gates and
schedule are linked. View Flight Details explains conflicts and lets you review
and correct the assignment. Airborne connections do not invent a departure time.
Aircraft swaps, teleports, clock changes and menu returns start a new observed
session. Landing away from an assigned destination is flagged for review.

FLIGHT LAB
The installer also includes Alpha 6 Flight Lab and its Start-menu shortcut.
Open Flight Lab, then choose Connect to Flight Lab in the OPS Flight Deck.
It records virtual phases and fault scenarios without launching MSFS.
Lab flights are clearly labeled and never attach a saved real flight assignment.
The dashboard also includes Dan's updated artwork, settings and offline globe.

SIMCONNECT RUNTIME
This local build is configured for the SDK SimConnect DLL installed in this
workspace. Keep that SDK component in place. simconnect-sdk-path.txt beside
Alpha6OPS.exe contains its full path; ALPHA6_SIMCONNECT_DLL can override it.
No Microsoft SDK binary is included in the archive or installer.
The app includes its own .NET runtime.

LOGS AND DIAGNOSTICS
Settings > Logs & Diagnostics contains local logs, telemetry journals and exports.
An observation continues while OPS is minimized to the tray.
Use Exit OPS to quit completely before installing an update.
Your saved settings, logs and SimBrief cache are preserved by installation.

PREVIEW LIMITS
The airport reference and matching tolerances are approximate. Some aircraft and
activities do not expose their route through the simulator plan interface.
Missing data stays unknown; there is no guarantee for every third-party add-on.
The network map, operational alerts and photograph are illustrative. Header
weather is for the computer's approximate location, not live aircraft weather.
