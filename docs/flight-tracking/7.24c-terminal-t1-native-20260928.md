## Scrollbar disposition

**Transient observation; cause unconfirmed; no reproducible layout defect established.** The user reports that the right-side scrollbar is absent on the subsequent normal start and reported no flicker in the traced run.

Source inspection shows the existing Operations outer ScrollViewer uses `VerticalScrollBarVisibility="Auto"`. Existing responsive layout changes map/panel dimensions with available width, and current flight/activity content can alter total page height. These are plausible overflow causes, not a proven explanation for this particular observation. The trace has no size-change notifications, but it did not record initial window dimensions or ScrollViewer extent/viewport/visibility; absence of resize events cannot establish whether content overflow occurred.

The trace launcher and observer do not add an Operations scrollbar or replace the workspace layout. Therefore the scrollbar is not described as a diagnostic-only feature. No scrollbar was hidden, no fixed dimensions were imposed, and no cadence or authoritative update was changed. If it recurs persistently or starts flashing again, capture the actual window/viewport and extent transitions before proposing a change. No additional parked repetition is requested solely for an absent scrollbar.
