## 9. Restoration architecture chosen

The existing Operations host retains one renderer for short internal navigation. Hidden projection offers stop; pending mailbox work is drained/cancelled; browser animations stop; the view collapses and native `TrySuspendAsync` suspends the document. On return, the same renderer resumes, receives the latest immutable overview, and remains transparent until the current snapshot/solar source is ready. A visibility generation rejects obsolete work and acknowledgments.

Five minutes dormant, real unload, Classic selection or renderer failure still disposes the renderer. No telemetry subscription moves into the map. The coordinator continues independently. A continuity-only break preserves already observed flown segments while starting a separate segment after hidden movement; it never draws a fabricated connecting line through that interval. Publication revalidates visibility/generation immediately before enqueueing to prevent a long-running old projection from entering the resumed mailbox.

This explicit retain/suspend/resume/dispose ownership can support a future persistent Home visualization, but a globe still needs its own GPU/workload budget. No globe or premium interface is implemented here.

## 11. Route-progress root cause

The final route projection clamps to the endpoint inside an existing 25 NM confidence corridor. A monotonic along-route cursor then latches total route length. Desktop consumers reconstructed remaining distance solely from fraction, yielding zero even when cross-track or beyond the destination. JST776's first incorrect sample is simulator 2026-09-27 22:11:45.2700805Z, 20.148087 NM from the filed endpoint, 8m10.997s before touchdown.

## 12. New progress semantics

Reliable remaining distance is `max(untraversed filed-route distance, actual great-circle distance to the filed destination reference point)`. Progress is `clamp(1 - remaining / filed route length, 0, 1)`. The internal continuity cursor remains monotonic; displayed geographic progress may decrease during vectors, overshoot or a go-around. Distance can exceed filed length, so consumers retain the numeric distance instead of deriving it only from a clamped percentage.

**Geographic 100% means the route endpoint has been reached; it does not mean block-in.** Confirmed valid Complete explicitly overrides progress/distance to 100%/zero; phase and actual IN remain operational authority. Touchdown/taxi alone do not create completion. Unreliable current estimates are withdrawn. Sub-100 values cannot round up to 100%; a positive distance below 0.1 NM is shown as `<0.1 NM`. Tooltip wording distinguishes geographic progress from lifecycle completion. No corridor threshold was loosened and no blanket 99% cap was added.

## 14. ETA semantics and correction

ETA means **gate IN in dated simulator UTC**, with the existing airborne calculation/schedule blend and taxi allowance. A phase transition publishes the appropriate prediction; an expired publication bypasses hysteresis; an expired schedule blend falls back to the live estimate; rounding cannot produce a past prediction. Paused/slewed stale estimates become unavailable. Confirmed actual IN is exact, not smoothed or rounded. Tests now inspect each taxi sample and cover midnight, approach/touchdown transitions, unreliable geometry, expired plans and suspended observations.
