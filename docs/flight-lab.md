# Flight Lab retired in v0.18.1

The companion app, named-pipe telemetry protocol/client, OPS connection controls and build target have been removed. The v0.18.1 installer replaces the old installation payload and removes the Flight Lab Start menu shortcut after a successful update.

OPS retains its shared .NET desktop runtime, native SimConnect integration, recorded-flight replay diagnostics and pilot data. Existing historical test flights remain readable in the logbook as legacy test flights.

Use the recorded-flight replay command documented in [checkpoint 7.13](checkpoint-7.13.md) for regression testing. Flight Lab is not required.
